# スカイライン・テクノロジーズ コーポレートサイト

架空のソフトウェア開発会社「スカイライン・テクノロジーズ」のコーポレートサイトです。
HTML・CSS・JavaScript を `index.html` の1ファイルにまとめた、1ページ構成のサイトです。

> ※ 本サイトに掲載している企業名・住所・電話番号・実績などはすべて架空のものです。

## 概要

| セクション | 内容 |
| --- | --- |
| ヘッダー | ロゴとナビゲーション。スクロールすると背景が白に切り替わります |
| お知らせ欄 | ナビゲーションの下に表示。5秒ごとに自動で切り替わり、「×」で閉じられます |
| メインビジュアル | キャッチコピー「テクノロジーで、ビジネスの空を広げる。」 |
| 私たちについて | 企業理念と3つの価値観（Clarity / Quality / Partnership） |
| 事業内容 | 業務システム、クラウド、AI・データ活用など6つのサービス |
| 実績の数字 | 創業年数・プロジェクト数などをカウントアップで表示 |
| 導入事例 | 物流・金融・小売の3事例 |
| 開発の進め方 | ヒアリングから運用改善までの4ステップ |
| ニュース | 最新のお知らせ一覧 |
| 採用情報 | 募集職種の一覧 |
| お問い合わせ | 入力フォーム（デモのため実際には送信されません）と会社情報 |

### 主な特徴

- パソコン・タブレット・スマートフォンの画面幅に合わせたレスポンシブデザイン
- スマートフォンではハンバーガーメニューに切り替え
- スクロールに合わせて各要素がふわっと表示されるアニメーション
- OSの「視差効果を減らす」設定が有効な場合はアニメーションを停止

## ファイル構成

```
company-site/
├── index.html   # サイト本体（HTML・CSS・JavaScript）
└── README.md    # このファイル
```

## ブラウザで index.html を開く手順

ビルドやインストールは不要です。以下のいずれかの方法で開けます。

### 方法1：ダブルクリックで開く

1. エクスプローラー（Mac の場合は Finder）で `company-site` フォルダを開きます。
2. `index.html` をダブルクリックします。
3. 既定のブラウザでサイトが表示されます。

### 方法2：ブラウザを指定して開く

1. `index.html` を右クリックします。
2. 「プログラムから開く」を選び、Google Chrome・Microsoft Edge などのブラウザを選択します。

### 方法3：ブラウザにドラッグ＆ドロップする

1. ブラウザを起動します。
2. `index.html` をブラウザのウィンドウにドラッグ＆ドロップします。

### 方法4：コマンドラインから開く

`company-site` フォルダで以下のコマンドを実行します。

```bash
# Windows（PowerShell / コマンドプロンプト）
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

### スマートフォン表示を確認する

1. ブラウザで `index.html` を開いた状態で `F12`（Mac は `Cmd + Option + I`）を押し、開発者ツールを開きます。
2. デバイス切り替えボタン（`Ctrl + Shift + M`、Mac は `Cmd + Shift + M`）を押します。
3. 画面上部で iPhone などの機種を選ぶと、スマートフォンでの表示を確認できます。

## 動作環境

- Google Chrome / Microsoft Edge / Safari / Firefox の最新版
- フォント（Noto Sans JP・Inter）は Google Fonts から読み込むため、インターネット接続が必要です。オフラインの場合は端末の標準フォントで表示されます。
